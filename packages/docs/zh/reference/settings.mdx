通过**文件 → 设置**或项目界面的设置按钮打开。流水线、服务商、翻译和排字更改会在短暂延迟后自动保存，并应用于所有窗口。

## 外观

选择浅色、深色、跟随系统，以及界面语言。这些设置不会改变页面渲染或翻译目标语言。

## 流水线

选择检测、OCR 和修复模型。所选模型显示自身的阈值或生成提示词等选项，模型配置分别保留。保存流水线设置时，只会重新加载设置有变化的阶段。

## 服务商

配置[翻译服务商](/zh/models/providers)中的连接。凭据使用系统凭据服务，URL 等非秘密字段使用共享配置。更改服务商会刷新模型发现。

## 翻译

选择服务商、模型、本地量化、目标语言与指令。生成控制包括采样、重复惩罚、每页最大 token、推理和图像输入。

**批处理**决定如何把页面分组为翻译请求。**自动**按模型的上下文窗口分组页面，并拆分仍然过大的请求。**所有页面**在一个请求中发送所有页面。**对半拆分**同样一次发送所有页面，请求过大时对半拆分，直到单个页面。**自定义**按**每个请求的页数**中设置的数量发送。最大 token 按页计算，因此包含多页的请求最多可生成该值乘以页数的 token，但每个请求不超过 32,768 个 token。

常用模型与输出选项也显示在画布处理选择器中。详见[翻译配置](/zh/models/translation)。

## 排字

设置默认字体家族优先顺序。首选字体不能提供所需字形时，Koharu 依次尝试此列表，最后使用系统回退。各文字图层仍保留自己的排字属性。

## 快捷键

为选择、文本、画笔、橡皮擦、取色器、移除、平移、适应窗口和适应宽度分配单字符。自定义工具键只在设置它们的窗口中生效，不会保存，Koharu 重启后会恢复默认值。

<Note>
  流水线、服务商、排字、Agent 与 HTTP 超时配置位于
  `~/.koharu/config.toml`，翻译设置属于流水线部分。凭据应分开保存，请使用设置界面，不要手动写入秘密值。
</Note>

项目和缓存位置见[数据位置](/zh/reference/data)。
