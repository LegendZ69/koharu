工具栏决定指针操作，检查器修改所选图层的持久属性。

## 导航与选择

用**平移**移动视图，通过状态栏调整缩放。**视图 → 适应窗口**或默认的 `0` 会显示完整页面。**视图 → 适应宽度**或默认的 `W` 会让页面填满画布宽度并从页面顶部开始，此时滚动和平移只会上下移动。切换页面时，即使缩放过，也会应用最后选择的适应方式。

用**选择**选中可编辑图层；按住 `Shift`、`Ctrl` 或 `Command` 可添加或移除图层。文字图层可以移动、缩放和旋转。只选中一个图层时会显示缩放和旋转控制柄；多选时只能移动。拖动时预览变换，结束时提交，取消则恢复之前的呈现。

## 选择编辑工具

<Tabs>
  <Tab title='文本'>
    单击创建点文本，拖动创建段落框。在检查器中输入译文，再设置[排字与适配](/zh/guides/typesetting)。
  </Tab>
  <Tab title='画笔与橡皮擦'>
    **画笔**按所选颜色和直径在选中的栅格图层上绘制；未选中栅格图层时会新建一个绘制图层。**橡皮擦**需要先选中栅格图层。两种工具也可以作用于图像修复生成的清理图层，在其上绘制后，该图层将归你所有。按住
    `Alt` 并滚动可调整直径。
  </Tab>
  <Tab title='取色器'>从合成后的画布取色，用于笔画或文字样式。</Tab>
  <Tab title='移除'>
    用**移除**涂抹原文字迹。松开笔画后会立即对该区域运行图像修复，并把结果合并到页面的清理图层；蒙版不会保留为图层。即使其他处理任务正在运行，笔画也会作为独立的处理任务启动。详见[清理原文](/zh/guides/cleanup)。
  </Tab>
</Tabs>

<Tip>
  按住 `Space` 或鼠标中键拖动可在不切换工具的情况下平移。滚动可平移，按住 `Shift`
  滚动可水平平移，按住 `Ctrl` 滚动可在指针位置缩放。`Escape` 取消当前手势并清空选择。
</Tip>

输入框获得焦点时，单键工具快捷键不生效。查看[快捷键](/zh/reference/shortcuts)。
